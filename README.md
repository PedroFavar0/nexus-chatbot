
# Nexus Chatbot

Chatbot inteligente para atendimento e qualificação
de clientes da Nexus Consultoria.

## Objetivo

Automatizar o primeiro atendimento comercial pelo
WhatsApp, oferecendo experiências personalizadas de
acordo com a origem do contato.

## Tecnologias

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- WhatsApp Cloud API
- OpenAI API

## Status

Em desenvolvimento.
